GEDT — Global Economic Digital Twin

Overview

GEDT is a computational research framework for economic simulation, experimentation, validation, and scenario analysis.

Core Areas

* Economic simulation
* Innovation modeling
* Statistical analysis
* Calibration
* Optimization
* Scenario analysis
* Reproducible experiments
* Validation and testing

Development Principle

GEDT is being reorganized from an experimental collection of code into a modular and testable research platform.

Existing working implementations will be preserved during migration.

Migration Strategy

1. Inventory existing GEDT code.
2. Establish the canonical package.
3. Migrate components one at a time.
4. Test after every migration.
5. Remove duplicates only after successful verification.
