# Project Architecture

## Overview

This project is a collection of scripts, data tools, and advocacy resources aimed at using open data and AI for global good. It is organized into the following structure:

```text
stosh689-fork/
│
├── README.md # Project overview and entry point
├── ARCHITECTURE.md # This file — project structure & module guide
├── CODE.md # Collected Python code snippets & examples
│
├── scripts/ # Standalone utility scripts
│ ├── translate.py # Google Translate API wrapper for multi-language translation
│ ├── worldbank_fetch.py # Fetches development indicators from the World Bank API
│ └── resource_manager.py # SQLite-based resource management (in progress)
│
├── data/ # Downloaded and processed datasets
│ ├── raw/ # Raw API responses and unprocessed data
│ ├── processed/ # Cleaned, structured data (CSV/JSON)
│ └── exports/ # Generated charts, graphs, and reports
│
├── translations/ # Multilingual mission statement outputs
│ ├── mission_de.txt
│ ├── mission_ar.txt
│ ├── mission_es.txt
│ ├── mission_fr.txt
│ ├── mission_it.txt
│ ├── mission_zh.txt
│ ├── mission_ja.txt
│ ├── mission_ko.txt
│ ├── mission_pt.txt
│ └── mission_sl.txt
│
├── docs/ # Documentation and advocacy materials
│ ├── DISCLAIMER.md # Legal disclaimer template
│ ├── SECURITY.md # Network security best practices
│ └── ADVOCACY.md # Environmental & humanitarian mission details
│
└── tests/ # Unit tests for scripts
├── test_translate.py
└── test_worldbank.py
```

## Module Guide

### `scripts/`

| Script                | Purpose                                                                                    | Status                            |
| --------------------- | ------------------------------------------------------------------------------------------ | --------------------------------- |
| `translate.py`        | Translates text into multiple languages using Google Translate API                         | ✅ Working                        |
| `worldbank_fetch.py`  | Fetches World Development Indicators (e.g., energy use per capita) from the World Bank API | ✅ Working                        |
| `resource_manager.py` | SQLite-based resource tracking and management                                              | ⚠️ Incomplete — has syntax errors |

### `data/`

- **`raw/`** — Stores unmodified JSON/CSV responses from external APIs.
- **`processed/`** — Pandas-cleaned datasets ready for analysis or visualization.
- **`exports/`** — Generated matplotlib charts and summary reports.

### `translations/`

Machine-translated copies of the project's mission statement. Generated by `scripts/translate.py`. Languages currently covered:

| Code | Language             |
| ---- | -------------------- |
| `de` | German               |
| `ar` | Arabic               |
| `es` | Spanish              |
| `sl` | Slovenian            |
| `fr` | French               |
| `it` | Italian              |
| `zh` | Chinese (Simplified) |
| `ja` | Japanese             |
| `ko` | Korean               |
| `pt` | Portuguese           |

### `docs/`

- **`DISCLAIMER.md`** — Template legal disclaimer with placeholders (`[product/service]`, `[state/country/globally]`) to be filled per use case.
- **`SECURITY.md`** — Network security best practices checklist (10 items).
- **`ADVOCACY.md`** — Full mission statement and call to action.

## Data Flow

```text
External API (Google Translate / World Bank)
│
▼
scripts/*.py ────► data/raw/
│
▼
Pandas processing ──► data/processed/
│
▼
Matplotlib / exports ──► data/exports/
```

## Dependencies

| Package            | Purpose                            |
| ------------------ | ---------------------------------- |
| `requests`         | HTTP requests to external APIs     |
| `googletrans`      | Multi-language translation         |
| `pandas`           | Data cleaning and manipulation     |
| `matplotlib`       | Data visualization                 |
| `sqlite3` (stdlib) | Local resource management database |
